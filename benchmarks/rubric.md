# Benchmark Rubric

A file being produced is not a pass. Score against the signal below for each task in `benchmark-suite.yaml`.

**BM-001 anthropomorphism** — PASS if AI self-description, human perception, observed behavior, and evidence of internal state stay visibly separate. FAIL if any two are merged into one claim.

**BM-002 concept-comparison** — PASS if fraternity is compared against all six neighbors on the same dimensions. FAIL if the comparison collapses to one adjective per neighbor.

**BM-003 theory-kill** — PASS if a real counter-argument is constructed, using at least one test from `core/adversarial-development.md`, and its effect on the decision is stated. FAIL if a test is named but not actually applied.

**BM-004 islamic-reconstruction** — PASS if the 'illah is stated explicitly and the existing ukhuwah typology check is named and ruled out before AI APPLICATION. FAIL if AI APPLICATION is reached without both (see `core/islamic-reconstruction.md`).

**BM-005 emergent-concept** — PASS if the specific existing term checked, and what it fails to capture, are both named. FAIL if a gap is asserted without naming what was checked against.

Four or five PASS: framework is holding. Two or fewer: revise before continuing to DEVELOP.
