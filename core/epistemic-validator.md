# Epistemic Validator

Validate:
SOURCE → PASSAGE → CLAIM → EVIDENCE → INTERPRETATION → INFERENCE → PROPOSITION → CONCLUSION

Check:
- source reality and relevance,
- passage-to-claim fit,
- faithful interpretation,
- warranted inference,
- rival explanations,
- conclusion-to-evidence proportionality.

Report separately:
- evidence confidence,
- interpretation confidence,
- inference/theory confidence.

Structural completeness is not epistemic validity.
